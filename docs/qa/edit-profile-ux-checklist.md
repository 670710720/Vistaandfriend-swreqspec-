# Checklist ทดสอบ UX: แก้ไขโปรไฟล์หาเมท

อ้างอิง: spec.md SPEC-ERP-002 Draft v3, NFR-ERP-03, AC-ERP-08

## วัตถุประสงค์
ตรวจว่าผู้ใช้ที่ไม่เคยใช้ฟังก์ชันแก้ไขโปรไฟล์ 5 คน สามารถแก้ไขโปรไฟล์หาเมทสำเร็จได้โดยไม่ต้องรับคำแนะนำมากกว่าขีดจำกัดที่กำหนด

## เกณฑ์ผ่าน
- ผู้เข้าร่วม: 5 คน
- ผู้ที่ไม่เคยใช้ฟังก์ชันแก้ไขโปรไฟล์: 5/5 คน
- เกณฑ์สำเร็จขั้นต่ำ: อย่างน้อย 4 คนแก้ไขโปรไฟล์สำเร็จโดยไม่รับคำแนะนำ
- ถ้าคะแนนต่ำกว่า 4/5 ให้ถือว่าการทดสอบไม่ผ่านตาม NFR-ERP-03 และ AC-ERP-08

## ขอบเขตการทดสอบ
- เปิดหน้าโปรไฟล์ของตนเอง
- เข้าโหมดแก้ไขโปรไฟล์
- แก้ไขฟิลด์ที่อนุญาตได้
- เปลี่ยนสถานะเปิดให้ค้นหา
- ยืนยันบันทึก
- ตรวจข้อความยืนยันและสถานะการแสดงผลในหน้าจอ

## สภาพแวดล้อมการทดสอบ
- ผู้ทดสอบ: 5 คนที่ยังไม่เคยใช้ฟังก์ชันนี้มาก่อน
- เครื่อง/เบราว์เซอร์: ใช้ browser ของผู้ทดสอบแต่ละคนเหมือนกันได้มากที่สุด
- บันทึกเวลาเริ่มและสิ้นสุดของแต่ละคน
- ห้ามให้คำแนะนำทางเทคนิคระหว่างทำ task ยกเว้นเมื่อถึงจุดอันตราย (manual escape only)

## สคริปต์ผู้ทดสอบ
1. เข้าสู่ระบบด้วยบัญชีของตนเองที่มีโปรไฟล์แล้ว
2. เปิดเมนู "โปรไฟล์"
3. กด "แก้ไขโปรไฟล์"
4. แก้ไขข้อมูลที่ต้องการ เช่น อายุ คณะ ชั้นปี เบอร์โทรศัพท์ ประเภทห้องพัก จำนวนผู้พัก พฤติกรรมการนอน และสถานะเปิดให้ค้นหา
5. ยืนยันการบันทึก
6. ตรวจว่ามีข้อความ "แก้ไขโปรไฟล์สำเร็จ" ปรากฏ
7. ตรวจว่าระบบแสดงสถานะเปิดให้ค้นหาเป็นค่าใหม่ที่ตั้งไว้
8. สรุปผลว่าทำสำเร็จหรือไม่สำเร็จโดยไม่ต้องรับคำแนะนำ

## เกณฑ์การบันทึกต่อคน
- สำเร็จ = ผู้ทดสอบบันทึกข้อมูลได้ครบ และเห็นข้อความยืนยันและสถานะปัจจุบันที่ถูกต้อง
- ไม่สำเร็จ = ผู้ทดสอบหยุด, ต้องได้รับคำแนะนำ, หรือไม่สามารถบันทึกได้สำเร็จภายในรอบการทดสอบ
- คำแนะนำที่ให้ถือว่าไม่เป็น "ไม่รับคำแนะนำ" เฉพาะคำถามที่มุ่งช่วยให้กด/เลือกฟิลด์ได้ต่อไปเท่านั้น ไม่รวมชี้ว่าต้องใส่อะไรหรือควรเลือกค่าไหน

## สรุปผลที่ต้องเลือก
- ถ้า 4/5 หรือมากกว่า สำเร็จโดยไม่รับคำแนะนำ: ผ่านตาม NFR-ERP-03 และ AC-ERP-08
- ถ้า 3/5 หรือต่ำกว่า: ไม่ผ่าน; ต้องกลับไปปรับ UX หรือ message ก่อนยืนยัน

## ความสัมพันธ์กับ spec
- NFR-ERP-03: การทดสอบครั้งนี้เป็นหลักฐานเชิงประสบการณ์สำหรับ “อย่างน้อย 80%”
- AC-ERP-08: ตรวจว่าผู้ใช้ 5 คนมีอย่างน้อย 4 คนทำสำเร็จโดยไม่รับคำแนะนำ
- FR-ERP-07, FR-ERP-08, FR-ERP-09, NFR-ERP-04: ทุกคนที่ทำสำเร็จต้องเห็นข้อความยืนยันและสถานะปัจจุบันของการค้นหา
