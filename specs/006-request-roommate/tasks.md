- สถานะ: พร้อมทำ

## สิ่งที่ยังไม่ทำ: Open Questions
- Q-RRS-01 ผู้รับสามารถได้รับคำขอจากนักศึกษาหลายคนพร้อมกันได้หรือไม่? -> ตอบแล้ว: ได้ ผู้รับรับคำขอที่รอการตอบรับจากหลายคนพร้อมกันได้; task ที่เกี่ยวข้อง: T-07, T-03
- Q-RRS-02 เมื่อผู้รับได้รับคำขอแล้ว สถานะหาเมทจะเปลี่ยนเป็นอะไร? -> ตอบแล้ว: คงสถานะกำลังหาเมทไว้จนกว่าจะตอบรับคำขอ; เกี่ยวข้องกับ T-03, T-05 แต่ไม่รอคำตอบเพิ่มและไม่มี task สถานะ "รอ Q-RRS-02"
- Q-RRS-03 ผู้ส่งสามารถยกเลิกคำขอที่ส่งไปแล้วได้หรือไม่? -> ตอบแล้ว: ยังไม่รวมในฟีเจอร์นี้ และจะเป็นฟีเจอร์แยกในภายหลัง; task ที่เกี่ยวข้อง: ไม่มี (ยังไม่เปิดใช้งานในฟีเจอร์นี้)
- Q-RRS-04 เมื่อมีคำขอซ้ำ ระบบควรแสดงข้อความแจ้งเตือนว่าอย่างไร? -> ตอบแล้ว: มีคำขอเป็นเมทกับผู้รับรายนี้อยู่แล้ว และยังอยู่ระหว่างรอการตอบรับ; task ที่เกี่ยวข้อง: T-03, T-09
- Q-RRS-05 คำขอเป็นเมทมีข้อความประกอบหรือไม่? -> ตอบแล้ว: มีข้อความประกอบแบบไม่บังคับ ความยาวไม่เกิน 500 ตัวอักษร; task ที่เกี่ยวข้อง: T-01, T-02, T-11
- Q-RRS-06 หากสถานะผู้รับหรือคำขอเดิมเปลี่ยนระหว่างเปิดหน้าส่งคำขอ ระบบต้องทำอย่างไร? -> ตอบแล้ว: ตรวจสอบสถานะและคำขอเดิมแบบ atomic อีกครั้งก่อนบันทึก และไม่บันทึกหากตรวจสอบไม่ผ่าน; task ที่เกี่ยวข้อง: T-01, T-09
- Q-RRS-07 หากมีการจับคู่สำเร็จกับผู้รับเดิมแล้ว จะส่งคำขอใหม่ได้หรือไม่? -> ตอบแล้ว: ส่งไม่ได้จนกว่าการจับคู่เดิมจะถูกยกเลิก; task ที่เกี่ยวข้อง: T-03, T-10
- Q-RRS-08 หากแจ้งเตือนผู้รับล้มเหลว ระบบต้องลองซ้ำกี่ครั้ง? -> ตอบแล้ว: ลองส่งซ้ำอัตโนมัติ 3 ครั้ง แล้วคงคำขอเป็น "รอการตอบรับ"; task ที่เกี่ยวข้อง: T-05, T-12
