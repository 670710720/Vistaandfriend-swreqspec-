## หมายเหตุสำหรับ AC-ERP-08 (T-10)
- การทดสอบนี้เป็นการทดสอบแบบผู้ใช้จริง (manual usability) ไม่ใช่ automated test
- ให้บันทึกผลจริง 5 คน โดยมีเงื่อนไขว่า 4/5 คนต้องดำเนินการสำเร็จโดยไม่รับคำแนะนำเพื่อให้ NFR-ERP-03 และ AC-ERP-08 ผ่าน
- คำแนะนำที่ให้เฉพาะการนำทางการใช้ UI เท่านั้น โดยไม่ควรบอกว่าต้องกรอกค่าใดหรือเลือกค่าใด
- ผลลัพธ์จริงของการทดสอบควรบันทึกลงใน [docs/qa/edit-profile-ux-checklist.md](../../docs/qa/edit-profile-ux-checklist.md)
