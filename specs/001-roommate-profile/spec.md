# Feature: สร้างโปรไฟล์หาเมท (Create Roommate Profile)
Spec ID: SPEC-RMP-001 | Source: SRS ข้อ ... (FR-RMP) | Use case: UC-01
Owner: ทีม vista and friend | Status: Draft v4 | Updated: 2569-11-12
## Goal
นักศึกษาสามารถสร้างโปรไฟล์เพื่อแสดงข้อมูลของตนเอง รวมถึงพฤติกรรมการนอนของตนเอง
เพื่อให้โปรไฟล์สามารถนำไปใช้ในการค้นหาและพิจารณารูมเมทที่เหมาะสมได้

## Scope
### In scope
- เปิดแบบฟอร์มสร้างโปรไฟล์หาเมท
- กรอกข้อมูลที่จำเป็นสำหรับการสร้างโปรไฟล์
- ระบุพฤติกรรมการนอนของผู้สร้างโปรไฟล์
- ตรวจสอบข้อมูลก่อนสร้างโปรไฟล์
- บันทึกโปรไฟล์หาเมท
- แสดงข้อความเมื่อสร้างโปรไฟล์สำเร็จ
- กำหนดสถานะเปิดให้ค้นหาโปรไฟล์

### Out of scope
- การแก้ไขข้อมูลโปรไฟล์หาเมท (UC-02)
- การลบโปรไฟล์หาเมท
- การค้นหาหรือจับคู่รูมเมท (UC-04) ยกเว้นการเผยแพร่โปรไฟล์ให้พร้อมแสดงในผลการค้นหา
- การติดต่อหรือแชทกับรูมเมท (UC-05)

## Constraints
- CON-AUTH-01 นักศึกษาต้องเข้าสู่ระบบก่อนจึงสามารถสร้างโปรไฟล์หาเมทได้
- CON-PROFILE-01 นักศึกษาต้องยังไม่มีโปรไฟล์หาเมทก่อนสร้างโปรไฟล์ใหม่
- CON-DATA-01 ข้อมูลที่จำเป็นต้องถูกกรอกครบก่อนจึงสามารถสร้างโปรไฟล์ได้
- CON-VALID-01 ข้อมูลที่กรอกต้องผ่านการตรวจสอบความถูกต้องก่อนบันทึก
- CON-REL-01 หากข้อมูลไม่ผ่านการตรวจสอบ ระบบต้องไม่สร้างโปรไฟล์
- CON-ROOM-01 ห้องแอร์รองรับจำนวนผู้พัก 1–4 คน และห้องพัดลมรองรับจำนวนผู้พัก 1–3 คน
- CON-DISCOVER-01 โปรไฟล์จะแสดงในผลการค้นหาได้ต่อเมื่อเจ้าของเปิดสถานะให้ค้นหา

## Requirements
- FR-RMP-01 ระบบต้องให้นักศึกษาสามารถเลือกเมนูสร้างโปรไฟล์หาเมทได้
- FR-RMP-02 ระบบต้องแสดงแบบฟอร์มสำหรับสร้างโปรไฟล์หาเมท
- FR-RMP-03 ระบบต้องให้นักศึกษาสามารถกรอกข้อมูลที่จำเป็นสำหรับการสร้างโปรไฟล์ได้
- FR-RMP-04 ระบบต้องให้นักศึกษาสามารถระบุพฤติกรรมการนอนของตนเองได้
- FR-RMP-05 ระบบต้องตรวจสอบข้อมูลที่นักศึกษากรอกก่อนสร้างโปรไฟล์
- FR-RMP-06 หากข้อมูลที่จำเป็นกรอกไม่ครบ ระบบต้องแจ้งให้นักศึกษากรอกข้อมูลที่จำเป็น
- FR-RMP-07 หากข้อมูลไม่ถูกต้อง ระบบต้องแจ้งข้อผิดพลาดและให้นักศึกษาแก้ไขข้อมูล
- FR-RMP-08 เมื่อข้อมูลผ่านการตรวจสอบ ระบบต้องบันทึกโปรไฟล์หาเมทของนักศึกษา
- FR-RMP-09 เมื่อสร้างโปรไฟล์สำเร็จ ระบบต้องแสดงข้อความว่าสร้างโปรไฟล์สำเร็จ
- FR-RMP-10 โปรไฟล์ที่สร้างสำเร็จต้องสามารถปรากฏในผลการค้นหาของนักศึกษาคนอื่นได้
- FR-RMP-11 ระบบต้องกำหนดสถานะการเปิดให้ค้นหาแยกจากการบันทึกโปรไฟล์ และอนุญาตให้เจ้าของเป็นผู้เปิดสถานะ

### Profile data and validation rules
- ข้อมูลที่จำเป็น ได้แก่ ชื่อเล่น อายุ เพศ คณะ ชั้นปี รูปโปรไฟล์ เบอร์โทรศัพท์ ประเภทห้องพัก และพฤติกรรมการนอน
- พฤติกรรมการนอนที่ระบุในโปรไฟล์เป็นข้อมูลของเจ้าของโปรไฟล์เท่านั้น และแยกจากความต้องการเกี่ยวกับพฤติกรรมการนอนของเมทที่จัดเก็บในฟีเจอร์ความต้องการหาเมท (UC-03)
- ข้อมูลโซเชียลช่องทางอื่น ได้แก่ Facebook, Instagram, LINE และ TikTok เป็นข้อมูลเสริม โดยรับ username หรือ URL
- อายุเป็นจำนวนเต็มระหว่าง 18–25 ปี
- เพศเลือกได้เฉพาะ หญิง หรือ ชาย
- คณะเลือกได้เฉพาะ วิทยาศาสตร์, เภสัชศาสตร์, วิศวกรรมศาสตร์, อักษรศาสตร์, มัณฑนศิลป์, ศิลปกรรม, ศึกษาศาสตร์ หรือ จิตรกรรม
- ชั้นปีเลือกได้เฉพาะ 1, 2, 3, 4 หรือ 5 ขึ้นไป
- รูปโปรไฟล์ต้องเป็นไฟล์ JPG หรือ PNG ขนาดไม่เกิน 5 MB โดยไม่ตรวจสอบมิติภาพ
- เบอร์โทรศัพท์ต้องมีตัวเลข 10 หลักหลังตัดช่องว่างหรือขีดคั่น และอนุญาตให้กรอกช่องว่างหรือขีดคั่นได้
- ประเภทห้องพักต้องระบุจำนวนผู้พักและรูปแบบห้อง โดยห้องแอร์เลือกได้ 1–4 คน และห้องพัดลมเลือกได้ 1–3 คน
- พฤติกรรมการนอนของผู้สร้างโปรไฟล์เป็นข้อมูลจำเป็น ต้องเลือกอย่างน้อยหนึ่งรายการจาก กรน, กัดฟัน, นอนดิ้น หรือ ไม่มีพฤติกรรมดังกล่าว โดยไม่มีตัวเลือก "อื่น ๆ" และห้ามเลือก "ไม่มีพฤติกรรมดังกล่าว" ร่วมกับตัวเลือกอื่น
- ความต้องการเกี่ยวกับพฤติกรรมการนอนของเมทที่ต้องการเป็นข้อมูลเสริมและจัดเก็บแยกในฟีเจอร์ความต้องการหาเมท (UC-03) ไม่ใช้ข้อมูลพฤติกรรมการนอนของเจ้าของโปรไฟล์แทนความต้องการดังกล่าว
- โปรไฟล์ที่สร้างสำเร็จต้องมีสถานะการเปิดให้ค้นหาเป็น "ไม่เปิด" จนกว่าเจ้าของจะเปิดสถานะ
- หากข้อมูลไม่ผ่าน validation ระบบต้องไม่บันทึกโปรไฟล์หรือข้อมูลบางส่วน

## Quality Requirements
- NFR-SEC-01 ระบบต้องอนุญาตให้เฉพาะนักศึกษาที่เข้าสู่ระบบแล้วสามารถสร้างโปรไฟล์หาเมทได้
- NFR-REL-01 ระบบต้องไม่สร้างโปรไฟล์ หากข้อมูลไม่ครบหรือข้อมูลไม่ถูกต้อง
- NFR-USE-01 ในการทดสอบกับนักศึกษาที่ไม่เคยใช้ฟังก์ชันนี้ 5 คน อย่างน้อย 80% ต้องสร้างโปรไฟล์หาเมทสำเร็จโดยไม่รับคำแนะนำ

## Acceptance Criteria
- [ ] AC-RMP-01 (FR-RMP-01, FR-RMP-02)
      Given นักศึกษาเข้าสู่ระบบแล้ว และยังไม่มีโปรไฟล์หาเมท
      When นักศึกษาเลือกเมนู "สร้างโปรไฟล์หาเมท"
      Then ระบบแสดงแบบฟอร์มสร้างโปรไฟล์หาเมท

- [ ] AC-RMP-01A (CON-PROFILE-01)
      Given นักศึกษาเข้าสู่ระบบแล้ว และมีโปรไฟล์หาเมทอยู่แล้ว
      When นักศึกษาเลือกเมนู "สร้างโปรไฟล์หาเมท"
      Then ระบบไม่แสดงแบบฟอร์มและแจ้งว่าไม่สามารถสร้างโปรไฟล์ใหม่ได้

- [ ] AC-RMP-02 (FR-RMP-03, FR-RMP-04)
      Given นักศึกษาอยู่ในหน้าแบบฟอร์มสร้างโปรไฟล์
      When นักศึกษากรอกข้อมูลที่จำเป็นและระบุพฤติกรรมการนอน
      Then แต่ละช่องแสดงค่าที่นักศึกษากรอก และพฤติกรรมการนอนที่เลือกยังคงถูกเลือกอยู่

- [ ] AC-RMP-02A (CON-VALID-01)
      Given นักศึกษาอยู่ในหน้าแบบฟอร์มสร้างโปรไฟล์
      When นักศึกษากรอกข้อมูลตามรายการตัวเลือกและช่วงค่าที่กำหนด
      Then ไม่มีข้อความผิดพลาดที่ช่องใด และปุ่มยืนยันการสร้างโปรไฟล์กดได้

- [ ] AC-RMP-03 (FR-RMP-05, FR-RMP-06)
      Given นักศึกษาอยู่ในหน้าแบบฟอร์มสร้างโปรไฟล์
      When นักศึกษากดยืนยันโดยกรอกข้อมูลที่จำเป็นไม่ครบ
      Then ระบบแจ้งให้นักศึกษากรอกข้อมูลที่จำเป็นและไม่สร้างโปรไฟล์

- [ ] AC-RMP-04 (FR-RMP-05, FR-RMP-07)
      Given นักศึกษาอยู่ในหน้าแบบฟอร์มสร้างโปรไฟล์
      When นักศึกษากดยืนยันโดยกรอกข้อมูลไม่ถูกต้อง
      Then ระบบแจ้งข้อผิดพลาดและให้นักศึกษาแก้ไขข้อมูลและไม่สร้างโปรไฟล์

- [ ] AC-RMP-04A (CON-ROOM-01)
      Given นักศึกษาอยู่ในหน้าแบบฟอร์มสร้างโปรไฟล์
      When นักศึกษาเลือกห้องพัดลมสำหรับผู้พัก 0 หรือ 4 คน หรือห้องแอร์สำหรับผู้พัก 5 คน แล้วกดยืนยัน
      Then ระบบแจ้งข้อผิดพลาดที่ช่องจำนวนผู้พัก และไม่สร้างโปรไฟล์

- [ ] AC-RMP-05 (FR-RMP-08, FR-RMP-09)
      Given นักศึกษากรอกข้อมูลครบและข้อมูลถูกต้อง
      When นักศึกษากดยืนยันการสร้างโปรไฟล์
      Then ระบบบันทึกโปรไฟล์หาเมทและแสดงข้อความว่าสร้างโปรไฟล์สำเร็จ

- [ ] AC-RMP-05B (FR-RMP-11, CON-DISCOVER-01)
      Given นักศึกษากรอกข้อมูลครบและข้อมูลถูกต้อง
      When ระบบสร้างโปรไฟล์สำเร็จ
      Then ระบบบันทึกโปรไฟล์ด้วยสถานะ "ไม่เปิด" และโปรไฟล์ยังไม่ปรากฏในผลการค้นหาจนกว่าเจ้าของจะเปิดสถานะ

- [ ] AC-RMP-05A (FR-RMP-08, NFR-REL-01)
      Given นักศึกษากรอกข้อมูลถูกต้องและกดยืนยันการสร้างโปรไฟล์
      When การบันทึกข้อมูลล้มเหลว
      Then ระบบไม่บันทึกข้อมูลบางส่วน แสดงข้อผิดพลาด และให้นักศึกษาลองใหม่ได้โดยไม่สร้างโปรไฟล์ซ้ำ

- [ ] AC-RMP-06 (FR-RMP-10)
      Given นักศึกษาสร้างโปรไฟล์หาเมทสำเร็จ
      When เจ้าของเปิดสถานะให้ค้นหาและนักศึกษาคนอื่นค้นหาโปรไฟล์หาเมท
      Then โปรไฟล์ของนักศึกษาปรากฏในผลการค้นหาได้
      หมายเหตุ: ในฟีเจอร์นี้ตรวจสถานะของโปรไฟล์ ส่วนหน้าค้นหาจริงตรวจร่วมกับ UC-04 (ตามหมวด Out of scope)

- [ ] AC-RMP-07 (NFR-USE-01)
      Given นักศึกษาที่ไม่เคยใช้ฟังก์ชันนี้จำนวน 5 คน
      When นักศึกษาแต่ละคนสร้างโปรไฟล์หาเมท
      Then อย่างน้อย 4 คนสร้างโปรไฟล์สำเร็จโดยไม่รับคำแนะนำ

- [ ] AC-RMP-08 (CON-DISCOVER-01)
      Given โปรไฟล์ของนักศึกษายังมีสถานะ "ไม่เปิด"
      When นักศึกษาคนอื่นค้นหาโปรไฟล์หาเมท
      Then ระบบไม่แสดงโปรไฟล์ดังกล่าวในผลการค้นหา
      หมายเหตุ: ในฟีเจอร์นี้ตรวจสถานะของโปรไฟล์ ส่วนหน้าค้นหาจริงตรวจร่วมกับ UC-04 (ตามหมวด Out of scope)

## Assumptions & Open Questions
- ASM-01 นักศึกษาต้องเข้าสู่ระบบก่อนใช้งานฟังก์ชันสร้างโปรไฟล์หาเมท
- ASM-02 นักศึกษาหนึ่งคนสามารถมีโปรไฟล์หาเมทได้หนึ่งโปรไฟล์
- ASM-03 ระบบเก็บข้อมูลโปรไฟล์ของนักศึกษาที่สร้างขึ้นใน SQLite ผ่าน backend
- ASM-04 โปรไฟล์ที่สร้างสำเร็จสามารถนำไปแสดงในผลการค้นหาของนักศึกษาคนอื่นได้

- Q-01 ข้อมูลใดบ้างที่เป็นข้อมูลจำเป็นสำหรับการสร้างโปรไฟล์?
-> ตอบแล้ว: ชื่อเล่น อายุ เพศ คณะ ชั้นปี รูปโปรไฟล์ เบอร์โทรศัพท์ ประเภทห้องพัก และพฤติกรรมการนอน
- Q-02 ความต้องการเกี่ยวกับเมทมีข้อมูลอะไรบ้าง?
-> ตอบแล้ว: ความต้องการเกี่ยวกับพฤติกรรมการนอนของเมทที่ต้องการเป็นข้อมูลเสริมและจัดเก็บใน UC-03; พฤติกรรมการนอนของผู้สร้างโปรไฟล์เป็นข้อมูลคนละส่วนที่จัดเก็บในโปรไฟล์ UC-01
- Q-03 หลังจากสร้างโปรไฟล์สำเร็จ โปรไฟล์จะแสดงในผลการค้นหาทันทีหรือไม่?
-> ตอบแล้ว: ต้องเปิดสถานะโดยเจ้าของก่อนจึงจะแสดงในผลการค้นหา
- Q-04 ถ้านักศึกษายังไม่ได้เข้าสู่ระบบแล้วเลือกเมนูสร้างโปรไฟล์หาเมท ระบบต้องทำอะไร (พาไปหน้าเข้าสู่ระบบ / ซ่อนเมนู / แสดงข้อความ)?
