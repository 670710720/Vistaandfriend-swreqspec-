## หน้าจอ (UI)

เพิ่มใน v3 (2569-11-11): mockup อยู่ในโฟลเดอร์ `mockups/` โดยไฟล์ `.html` สำหรับ AI อ่านและทดลองเปิดดู ส่วนไฟล์ `.png` สำหรับคนตรวจหน้าจอ ภาพตัวอย่างใช้ข้อมูลสมมติและเป็นแนวทางการจัดวางเท่านั้น หาก mockup ขัดกับข้อความใน spec ให้ถือ spec เป็นหลัก และบันทึกประเด็นที่ยังไม่ชัดเจนเป็น Q-xx ก่อนเปลี่ยนข้อกำหนด

- **UI-SRS-01 ค้นหาเมทและระบุเงื่อนไข:** `mockups/UI-SRS-01-search-filters.html` / `mockups/UI-SRS-01-search-filters.png` รองรับ: FR-SRS-01, FR-SRS-02, FR-SRS-03, FR-SRS-04 ต้องตรง: เข้าถึงได้หลังเข้าสู่ระบบและมีโปรไฟล์หาเมท แสดงฟอร์มตัวกรอง แก้ไขค่าได้ก่อนค้นหา มีตัวเลือกโหมด AND/OR และมีตัวกรองพฤติกรรมการนอน ความสะอาด และเวลาเข้านอน ยืดหยุ่นได้: สี ระยะห่าง รูปแบบช่องกรอก ไอคอน และข้อความช่วยอธิบาย ทั้งนี้ชื่อ/ชนิดของตัวกรองอื่นให้ยึดรายการใน `plan.md` และ spec เป็นหลัก
- **UI-SRS-02 รายการผลการค้นหาและแบ่งหน้า:** `mockups/UI-SRS-02-search-results.html` / `mockups/UI-SRS-02-search-results.png` รองรับ: FR-SRS-04, FR-SRS-05, FR-SRS-08, FR-SRS-09 ต้องตรง: แสดงรายการโปรไฟล์ที่ผ่านเงื่อนไข แสดงข้อมูลสำคัญและจำนวนเงื่อนไขที่ตรงกัน เรียงตามจำนวนที่ตรงจากมากไปน้อยตามกติกา AND/OR และมีตัวควบคุมเปลี่ยนหน้าไม่เกิน 20 รายการต่อหน้า เมื่อค้นหาใหม่ต้องกลับหน้า 1 ยืดหยุ่นได้: รูปแบบบัตร/ตาราง สี ป้ายกำกับ และระยะห่าง
- **UI-SRS-03 รายละเอียดโปรไฟล์เมท:** `mockups/UI-SRS-03-profile-detail.html` / `mockups/UI-SRS-03-profile-detail.png` รองรับ: FR-SRS-06 ต้องตรง: เปิดรายละเอียดของโปรไฟล์ที่เลือก แสดงเฉพาะข้อมูลโปรไฟล์และความต้องการที่อนุญาต รวมช่องทางโซเชียลที่อนุญาต และห้ามแสดงเบอร์โทรศัพท์ ยืดหยุ่นได้: การจัดกลุ่มข้อมูล รูปแบบบัตร สี และระยะห่าง
- **UI-SRS-04 ยังไม่มีโปรไฟล์หาเมท:** `mockups/UI-SRS-04-no-roommate-profile.html` / `mockups/UI-SRS-04-no-roommate-profile.png` รองรับ: CON-SRS-02 ต้องตรง: แจ้งว่าต้องสร้างโปรไฟล์หาเมทก่อนใช้งาน และมีทางลัดไปหน้าสร้างโปรไฟล์ ยืดหยุ่นได้: ภาพประกอบ สี และข้อความอธิบายเพิ่มเติม
- **UI-SRS-05 ไม่พบผลการค้นหา:** `mockups/UI-SRS-05-no-search-results.html` / `mockups/UI-SRS-05-no-search-results.png` รองรับ: FR-SRS-07, CON-SRS-05 ต้องตรง: เมื่อไม่มีรายการตรงเงื่อนไข แสดงข้อความ “ไม่พบผลการค้นหา” และให้ผู้ใช้กลับไปแก้ไขตัวกรองได้ ยืดหยุ่นได้: ภาพประกอบ สี และคำแนะนำเพิ่มเติม

**หมายเหตุการครอบคลุมหน้าจอ:** การปฏิเสธผู้ใช้ที่ยังไม่เข้าสู่ระบบ (AC-SRS-06) ใช้กลไกป้องกัน route และพาไปหน้าเข้าสู่ระบบเดิม จึงไม่ทำ mockup หน้า login ซ้ำ ส่วน AC-SRS-08 เป็นการทดสอบ usability ไม่ใช่หน้าจอแยก

**หมายเหตุข้อมูลในภาพ:** ค่าในตัวอย่าง เช่น คณะ ชั้นปี งบประมาณ พื้นที่ และชื่อบุคคล เป็นข้อมูลสมมติที่ใส่เพื่อให้เห็นโครงร่างหน้าจอ ไม่ใช่การเพิ่มข้อกำหนดตัวกรองใหม่ รายการตัวกรองจริงต้องตรวจเทียบกับ `plan.md` ก่อนพัฒนา
