# Feature: ติดต่อ/แชทกับรูมเมท (Chat with Roommate)
Spec ID: SPEC-CHAT-002 | Source: SRS ข้อ ... (FR-CHAT) | Use case: UC-02
Owner: ทีม vista and friend | Status: Draft v1 | Updated: 2569-09-09

## Goal
นักศึกษาสามารถเลือกนักศึกษาที่ต้องการติดต่อ เปิดหน้าต่างแชท
ส่งและรับข้อความ เพื่อพูดคุยและตกลงรายละเอียดเกี่ยวกับการพักอาศัยร่วมกัน

## Scope
### In scope
- เลือกนักศึกษาที่ต้องการติดต่อ
- เปิดหน้าต่างแชทระหว่างนักศึกษาสองคน
- ส่งและรับข้อความ
- บันทึกประวัติข้อความ
- แสดงข้อความที่ส่งและได้รับ
- ใช้การแชทเพื่อพูดคุยและตกลงเรื่องห้องพัก

### Out of scope
- การค้นหาหรือจับคู่รูมเมท (UC-01)
- การจัดการข้อมูลโปรไฟล์นักศึกษา

## Constraints
- CON-AUTH-01 นักศึกษาต้องเข้าสู่ระบบก่อนจึงสามารถใช้งานระบบแชทได้
- CON-PRIV-01 ข้อความในการสนทนาต้องสามารถเข้าถึงได้เฉพาะนักศึกษาที่อยู่ในการสนทนา
- CON-DATA-01 ข้อความที่ส่งต้องถูกบันทึกลงในฐานข้อมูลก่อนหรือพร้อมกับการส่งข้อความ
- CON-TECH-01 ระบบต้องสามารถรองรับการส่งข้อความระหว่างนักศึกษาหลายคู่พร้อมกัน
- CON-REL-01 หากการส่งข้อความไม่สำเร็จ ระบบต้องไม่บันทึกข้อความเป็นข้อความที่ส่งสำเร็จ

## Requirements
- FR-CHAT-01 ระบบต้องให้นักศึกษาสามารถเลือกนักศึกษาที่ต้องการติดต่อได้
- FR-CHAT-02 ระบบต้องเปิดหน้าต่างแชทของนักศึกษาที่เลือก
  และแสดงประวัติการสนทนาระหว่างนักศึกษาทั้งสองคน
- FR-CHAT-03 ระบบต้องให้นักศึกษาสามารถพิมพ์และส่งข้อความได้
- FR-CHAT-04 เมื่อส่งข้อความสำเร็จ ระบบต้องบันทึกข้อความ
  พร้อมข้อมูลผู้ส่ง ผู้รับ และเวลาที่ส่ง
- FR-CHAT-05 ระบบต้องส่งข้อความให้ผู้รับและแสดงข้อความในหน้าต่างแชท
- FR-CHAT-06 ระบบต้องแสดงข้อความใหม่ที่ผู้รับได้รับในหน้าต่างแชท
- FR-CHAT-07 ระบบต้องแจ้งเตือนนักศึกษาเมื่อไม่สามารถส่งข้อความได้
  และต้องไม่แสดงข้อความดังกล่าวว่าเป็นข้อความที่ส่งสำเร็จ
- FR-CHAT-08 ระบบต้องให้นักศึกษาสามารถเปิดดูประวัติการสนทนาเดิมได้

## Quality Requirements
- NFR-PERF-01 การส่งข้อความต้องมีเวลาตอบสนองไม่เกิน 3 วินาที
  ภายใต้จำนวนผู้ใช้พร้อมกันตามที่ระบบกำหนด
- NFR-SEC-01 ระบบต้องป้องกันไม่ให้ผู้ใช้ที่ไม่ได้อยู่ในการสนทนา
  สามารถเข้าถึงข้อความได้
- NFR-REL-01 ข้อความที่ส่งสำเร็จต้องไม่สูญหายและต้องสามารถเรียกดูย้อนหลังได้
- NFR-USE-01 นักศึกษาสามารถเปิดแชทและส่งข้อความได้โดยไม่ต้องได้รับความช่วยเหลือ

## Acceptance Criteria
- [ ] AC-CHAT-01 (FR-CHAT-01, FR-CHAT-02)
      Given นักศึกษาเข้าสู่ระบบแล้ว และมีนักศึกษาที่ต้องการติดต่อ
      When  นักศึกษาเลือกนักศึกษาคนนั้น
      Then  ระบบเปิดหน้าต่างแชทและแสดงประวัติการสนทนา

- [ ] AC-CHAT-02 (FR-CHAT-03, FR-CHAT-04)
      Given นักศึกษาเปิดหน้าต่างแชทแล้ว
      When  นักศึกษาพิมพ์ข้อความและกดส่ง
      Then  ระบบบันทึกข้อความ พร้อมผู้ส่ง ผู้รับ และเวลาที่ส่ง

- [ ] AC-CHAT-03 (FR-CHAT-05, FR-CHAT-06)
      Given นักศึกษาส่งข้อความสำเร็จ
      When  ผู้รับเปิดหน้าต่างแชท
      Then  ผู้รับสามารถเห็นข้อความที่ส่งมาได้

- [ ] AC-CHAT-04 (FR-CHAT-07)
      Given ระบบไม่สามารถส่งข้อความได้
      When  นักศึกษากดส่งข้อความ
      Then  ระบบแจ้งเตือนว่าไม่สามารถส่งข้อความได้
      และข้อความไม่ถูกแสดงเป็นข้อความที่ส่งสำเร็จ

- [ ] AC-CHAT-05 (FR-CHAT-08, NFR-REL-01)
      Given นักศึกษามีประวัติการสนทนาเดิม
      When  นักศึกษาเปิดหน้าต่างแชท
      Then  ระบบแสดงข้อความในการสนทนาที่เคยบันทึกไว้

- [ ] AC-CHAT-06 (NFR-SEC-01)
      Given ผู้ใช้ไม่ได้เป็นผู้ส่งหรือผู้รับในการสนทนา
      When  ผู้ใช้พยายามเข้าถึงข้อความ
      Then  ระบบปฏิเสธการเข้าถึงข้อความดังกล่าว

## Assumptions & Open Questions
- ASM-01 นักศึกษาที่สามารถเลือกติดต่อได้ต้องเป็นนักศึกษาที่อยู่ในระบบ
  และสามารถจับคู่เป็นรูมเมทได้
- ASM-02 นักศึกษาต้องเข้าสู่ระบบก่อนใช้งานฟังก์ชันแชท
- ASM-03 ระบบเก็บวันและเวลาของข้อความตามเขตเวลา Asia/Bangkok
- ASM-04 การพูดคุยและตกลงเรื่องห้องพักผ่านแชทถือเป็นการสื่อสารระหว่างนักศึกษา
  ระบบไม่ได้ทำหน้าที่เป็นสัญญาการเช่าหรือการยืนยันการจองห้อง

- Q-01 ต้องการให้ระบบแจ้งเตือนเมื่อมีข้อความใหม่หรือไม่?
  -> ถามผู้ใช้งาน
- Q-02 ต้องการให้สามารถส่งเฉพาะข้อความ หรือรองรับรูปภาพ/ไฟล์ด้วย?
  -> ถามผู้ใช้งาน
- Q-03 ต้องการให้แสดงสถานะอ่านข้อความแล้ว (Read) หรือไม่?
  -> ถามผู้ใช้งาน
